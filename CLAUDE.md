# CLAUDE.md — Laravel AI-First Starter Kit

Modular Laravel 13 monolith (PHP ≥ 8.3) with Blade + Alpine + Tailwind 4 UI, a versioned JSON API,
MySQL + Redis, and quality gates that enforce the rules below. Default UI locale **fa (RTL)**, also **en (LTR)**.
Code, comments, commits and technical docs are in **English**.

> This file is the source of truth for agents. Generic Laravel guidance generated by Laravel Boost lives in
> [`docs/ai/laravel-boost.md`](docs/ai/laravel-boost.md); where it conflicts with this file, **this file wins**.

## Architecture in 30 seconds

- `app/Modules/<Name>/` — one business domain per module: `Actions/ Data/ Enums/ Events/ Exceptions/ Http/{Controllers,Requests,Resources}/ Jobs/ Listeners/ Models/ Notifications/ Policies/ Providers/ Queries/ ValueObjects/ Database/{Migrations,Factories,Seeders}/ resources/views/ lang/{en,fa}/ routes/{web,api}.php`.
- `app/Shared/` — cross-cutting: `ModuleServiceProvider` base, `DomainException`, RFC 9457 problem details, middleware, navigation & permission registries, localization, date formatting.
- Flow: **FormRequest** (validate + authorize + `toData()`) → **thin Controller** → **Action** (writes) / **Query** (reads) → Blade view (UI kit) or API Resource.
- Modules talk only through another module's `Contracts/ Data/ Enums/ Events/` (+ `Users\Models\User`).
- **Reference module: `app/Modules/Blog`** — copy its patterns. Details: [`docs/architecture.md`](docs/architecture.md).

## Golden rules (each is enforced — see [`docs/conventions.md`](docs/conventions.md))

1. `declare(strict_types=1);`, `final` classes, full types (100% type coverage), PHPStan **max**, no baseline.
2. Controllers never touch Eloquent (no `Model::query()`, `->save()`, `->where()`…). Writes → Action, reads → Query object.
3. Actions: `final readonly`, verb-noun name **without** `Action` suffix, one public `handle()`, take DTOs, no Facades (inject contracts), throw `DomainException` subclasses.
4. DTOs (`Data/*Data`) and Value Objects are `final readonly`. Only validated input (`$request->toData()`) reaches Actions.
5. Models: relations, casts, scopes, accessors only — no business methods. ULID keys. Strict mode is on (lazy loading throws → eager-load in Queries).
6. No magic strings: enums for statuses/roles/permissions/settings; config for tunables; `env()` only in `config/`.
7. No hard-coded user-visible text: `__()` with keys in **both** `lang/en` and `lang/fa` (module: `__('blog::posts.created')`).
8. Blade: UI kit only (`<x-ui.*>`, `<x-layouts.app|guest|admin>`), **logical** direction classes (`ms-/me-/ps-/pe-/text-start`), token colors (`bg-surface`, `text-fg-muted`, `bg-primary`), no queries in views, `{!! !!}` only with a `{{-- unescaped: reason --}}` comment.
9. Authorization only through Policies/Gates with permission enums. Admin pages use the `admin` middleware group.
10. API: `/api/v1`, Sanctum, Resources, errors are problem+json (automatic). Docs at `/docs/api`.
11. Never cross module boundaries; expose a `Contracts\` interface or dispatch an event instead.
12. Every non-obvious decision gets an ADR (`docs/adr/`, skill `write-adr`).

## Commands

```bash
composer check        # EVERYTHING CI runs: lint + analyse + test + type coverage. Must be green.
composer fix          # Rector → Pint → Prettier (run before check when lint fails)
composer test         # Pest (unit, feature, arch)     ./vendor/bin/pest --filter=Publish
composer analyse      # PHPStan / Larastan level max
make setup | up | fresh | check   # Docker (Sail) workflow
npm run dev | build   # Vite
php artisan make:module Name | make:action Module VerbNoun | make:dto | make:query | make:value-object | make:ui-component
php artisan permissions:sync      # after adding permission enums
```

Local URLs: app `http://localhost`, style guide `/_styleguide`, API docs `/docs/api`, Mailpit `:8025`, Horizon `/horizon`, Pulse `/pulse`, Telescope `/telescope` (local).
Seeded login: `admin@example.com` / `password` (super-admin).

## Definition of done

- [ ] `composer check` green (and `npm run build` if front-end changed)
- [ ] Tests for every new Action (success + each exception) and route (guest / 403 / invalid / success)
- [ ] Translations in fa **and** en; pages checked in RTL and LTR
- [ ] Docs updated (CHANGELOG `[Unreleased]`, `docs/api.md` for endpoints, ADR for decisions)
- [ ] Conventional Commit: `feat(blog): add post scheduling`

## Never

- Edit `.env`, `vendor/`, `node_modules/`, or a migration that is already committed (hooks block it) — add a new migration.
- Add `@phpstan-ignore`, baseline entries, `->skip()` or lower a rule to get green. Fix the cause (`fix-failing-check` skill).
- Put logic in controllers, models or views; use Facades in Actions/Data/Models/Queries/ValueObjects/Events/Enums.
- Import another module's `Actions/Models/Queries/Http/...` (arch test `ModuleBoundariesTest`).
- Use `dd`, `dump`, `ray`, `var_dump`, physical Tailwind direction classes, or raw palette colors.
- Use PHP 8.4+ syntax — the floor is **8.3**: no property hooks, no asymmetric visibility, write `(new Foo())->bar()` (not `new Foo()->bar()`).
- Install packages without the `researcher` agent checking versions, or commit secrets.

## How to work here (agents)

- Feature work: **`/feature <description>`** — architect → laravel-builder + blade-ui-builder → test-writer → code-reviewer ∥ security-auditor → qa-verifier → docs-keeper.
- Other commands: `/new-module <Name>`, `/review`, `/check`, `/adr <topic>`, `/audit`.
- Subagents (`.claude/agents/`): researcher, architect, laravel-builder, blade-ui-builder, test-writer, code-reviewer, security-auditor, qa-verifier, docs-keeper.
- Skills (`.claude/skills/`): new-module, new-action, web-crud, api-endpoint, blade-component, migration-model, events-jobs, i18n-rtl, writing-tests, write-adr, fix-failing-check. **Read the matching skill before you start a step.**
- Hooks (`.claude/settings.json`): Pint runs after every PHP edit; edits to `.env`/`vendor`/committed migrations are blocked; on stop, arch tests + PHPStan run on changed files and must pass.
- Laravel Boost MCP (`.mcp.json`): use `search-docs` for version-correct Laravel docs, `database-schema`, `list-routes`, `read-log-entries`.
